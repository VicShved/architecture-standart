# Крупные задачи по системам (Task4 — передача ставок в кол-центр)

Список крупных задач для будущего планирования, сформирован на основе ADR [ADR_передача_ставок_в_кол-центр_MVP.md](ADR_передача_ставок_в_кол-центр_MVP.md), диаграммы [c4_containers.puml](c4_containers.puml) и RoadMap [RoadMap.drawio](RoadMap.drawio).

## 1. Сервис депозитов (силы банка, .NET + MS SQL)

- DS-0 (MVP). Реализация сервиса в части ставок.
- DS-1 (MVP). Публикация ставок в Kafka.
- DS-2 (MVP). Экспорт ставок: формирование файла актуальных ставок (версия, дата, контрольная сумма) и выгрузка на SFTP.

## 2. Система кол-центра (подрядчик платформы + Java-экспертиза банка)

- CC-1 (MVP). Приём событий и ведение локальной модели ставок: микросервис приёма событий (Java Spring Boot, Spring Kafka), локальная модель в PostgreSQL.
- CC-2 (MVP). API и интерфейс оператора: API ставок и раздел «Депозитные ставки» с отображением актуальности.

## 3. Партнёрский кол-центр (внешняя организация)

- PC-1 (MVP). Приём и разбор файла с SFTP-сервера обмена и загрузка ставок в систему партнёра.
- PC-2 (MVP). Тестовый обмен и приёмка совместно с банком.

## 4. ИТ / ИБ / инфраструктура (банк)

- IT-0 (MVP). Разворачивание Kafka.
- IT-1 (MVP). Требования ИБ к внешнему файловому обмену (только ставки, без ПДн; шифрование канала).
- IT-2 (MVP). SFTP-сервер в периметре (DMZ) и сетевые доступы: развёртывание сервера, доступ по ключам, ограничение по IP.

## 5. Сервис мониторинга (силы банка, второе полугодие)

- MON-1. Централизованный мониторинг и алертинг передачи ставок: сбор метрик и журналов публикации событий и файлового обмена, дашборды и алерты по задержкам/сбоям доставки в кол-центры.

## 6. Целевое решение (горизонт года)

- Ц-1. Персональные ставки, обмен с партнёром почти в реальном времени и автосверка.
- Ц-2. Полное покрытие депозитных продуктов и отказ от ручных процессов.

## 7. АБС

- ABS-1. Изменений не требуется: ставки ведутся в Сервисе депозитов (решение Task3), АБС в передаче ставок не участвует.
